Morning Alpha · 金融早餐

本地使用：
1. 确认电脑已安装 Python 3。
2. 双击“启动晨报.bat”。
3. 浏览器打开 http://localhost:8765

程序会抓取公开 RSS，并缓存 6 小时；打开网页时会自动读取最新内容。
如果某个资讯源暂时不可用，页面仍会显示其他来源的内容。

说明：
- 当前版本适合个人本地使用。
- 资讯只保留标题、摘要和原文链接，不复制新闻全文。
- 内容来自公开资讯源，重要信息请回到原文或官方渠道核实。

公网版：
https://dahlia-827.github.io/Morning-Alpha/

GitHub Actions 每 4 小时自动抓取资讯、更新 news_cache.json 并重新发布网页。
本地的 C:\... 路径只属于这台电脑，不是公网地址；访问公网版必须使用上面的 https 地址。

来源标记：
- 国内可访问：优先使用中国大陆官方或主流财经来源。
- 可能需代理：海外来源，点击前请留意网络环境。

当前接入的来源体系：
- 国家统计局：最新发布、数据解读 RSS。
- Federal Reserve：美联储官方新闻 RSS。
- U.S. SEC：美国证券交易委员会新闻 RSS（可能需代理）。
- 主题聚合：AI、美国资本市场、中国政策与产业、商业决策、全球市场。

微博等平台建议只接入公开官方账号或公开内容，不抓取登录后内容，也不复制全文。
